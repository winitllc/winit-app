# What's In It - Util Service

## Image Service Functions
* saveImage (unused) - POST
* imageToText (unused) - POST

## KMS Service Functions
* awsCredentials - GET - retrieves the IAM credentials from KMS for authenticating with Rekognition
* chompAPIKey - GET - retrieves the Chomp API key from KMS for authenticating with Chomp API https://chompthis.com/api/
